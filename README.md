# خرچہ دوست (Kharcha Dost) - Expense Manager App

ایک مکمل اینڈرائیڈ ایپ جو آپ کی فراہم کردہ ایکسل شیٹ اور ضروریات کے عین مطابق تیار کی گئی ہے۔

### شامل کردہ خصوصیات:
1. **SMS آٹو ریڈنگ:** JazzCash, EasyPaisa, SadaPay اور بینک ٹرانزیکشنز خود بخود ریڈ ہو کر ایپ میں شامل ہوتی ہیں۔
2. **محفوظ یومیہ خرچ میٹر (Safe-to-Spend Meter):** ہر روز کی محفوظ حد بتاتا ہے تاکہ مہینے کے آخر میں پیسے ختم نہ ہوں۔
3. **ایکسل خودکار کنورژن:** بٹن دباتے ہی موبائل کے اندر آپ کی اصل شیٹ کے فارمیٹ پر `.xlsx` فائل تیار ہو جاتی ہے۔
4. **انوائس سلپ سسٹم (PDF Print/Share):**
   - تمام اخراجات کی اکٹھی انوائس سلپ۔
   - الگ الگ مدات (صرف چائے، صرف رکشہ، صرف لنچ، یا صرف ایکسٹرا خرچے) کی سلپ۔
5. **مکمل آف لائن SQLite ڈیٹا بیس:** بغیر انٹرنیٹ کے موبائل میں ڈیٹا محفوظ رہتا ہے۔

### موبائل کے لیے APK بنانے کا طریقہ:
1. پروجیکٹ فولڈر کھولیں۔
2. ٹرمینل میں کمانڈ چلائیں:
   ```bash
   flutter pub get
   flutter build apk --release
   ```
3. تیار شدہ فائل `build/app/outputs/flutter-apk/app-release.apk` میں مل جائے گی جسے آپ براہِ راست اپنے موبائل میں انسٹال کر سکتے ہیں۔
